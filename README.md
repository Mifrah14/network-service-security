# Network-service-security
Hands-on cybersecurity project covering network security fundamentals, service-level attacks, and a practical DNS spoofing lab via ARP poisoning.

A hands-on cybersecurity project covering core network security concepts, 
common network service vulnerabilities, and a practical lab demonstrating 
a DNS spoofing attack via ARP cache poisoning.

## 📋 Topics Covered
- Network traffic fundamentals & port security
- Deprecated / vulnerable network protocols
- DHCP and DNS: functionality, attacks, and mitigations
- NTP servers and their forensic significance
- Two additional network services (research-based)
- Hands-on Lab: DNS spoofing via ARP cache poisoning (Kali + Ettercap)

## 🛠️ Tools Used
- Kali Linux (VM)
- Ettercap
- Python (for lab web server)
- VirtualBox / VMware (for isolated lab network)
